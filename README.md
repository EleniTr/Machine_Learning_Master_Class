Επεξεργασία Δεδομένων


Τα δεδομένα του household features ενώθηκαν με τις ετικέτες κατανάλωσης (cons_ppp17) μέσω των keys survey_id και hhid. Επαληθεύτηκε η απουσία διπλοεγγραφών και ελλειπουσών τιμών στη μεταβλητή-στόχο.


Αφαιρέθηκαν χαρακτηριστικά χωρίς διακύμανση, καθώς και αναγνωριστικά πεδία (survey_id, hhid) που δεν συνεισφέρουν στην πρόβλεψη. Επιπλέον, αφαιρέθηκε η μεταβλητή φύλου για αποφυγή εισαγωγής μεροληψίας.


Οι κατηγορικές μεταβλητές με δύο μοναδικές τιμές μετατράπηκαν σε δυαδική αριθμητική μορφή (0/1), ενώ για μεταβλητές με περισσότερες κατηγορίες εφαρμόστηκε one-hot encoding.


Δημιουργήθηκαν σύνθετα χαρακτηριστικά μέσω σύνοψης ομάδων μεταβλητών, όπως συνολική κατανάλωση τροφίμων, αριθμός παιδιών και δείκτης απασχολούμενων ενηλίκων, μειώνοντας τη διαστασιμότητα των δεδομένων.


Οι ελλείπουσες τιμές στις αριθμητικές μεταβλητές συμπληρώθηκαν με τη διάμεσο, ενώ στις κατηγορικές με την επικρατέστερη τιμή (mode).




Το τελικό σύνολο δεδομένων δεν περιέχει ελλείπουσες τιμές και αποτελείται αποκλειστικά από αριθμητικά χαρακτηριστικά.


Επίσης, κατά την προετοιμασία του test set εφαρμόστηκε επιπλέον imputation ώστε να αφαιρεθούν πλήρως τα missing values, καθώς το Gradient Boosting δεν υποστηρίζει NaN τιμές κατά την πρόβλεψη.
  
Επεξήγηση Αποτελεσμάτων


* Περιορισμοί των μοντέλων


Lasso Regression

Υποθέτουν γραμμική σχέση μεταξύ χαρακτηριστικών και στόχου, γεγονός που περιορίζει την ικανότητά τους να αποτυπώσουν τις πολύπλοκες μη γραμμικές αλληλεπιδράσεις των δεδομένων του dataset..

Support Vector Regression(SVR)

Αυξημένο υπολογιστικό κόστος και ευαισθησία στην επιλογή υπερ παραμέτρων (kernel, C, γ), ενώ η ερμηνευσιμότητά τους είναι περιορισμένη.

Gradient Boosting

Παρότι προσφέρουν υψηλή ακρίβεια, χρειάζεται πολύ καλό  fine-tuning για αποφυγεί overfitting των αποτελεσμάτων και έχουν μειωμένη διαφάνεια ως προς τη λήψη αποφάσεων.

Deep Learning - MLP

Απαιτούν επαρκή ποσότητα δεδομένων και προσεκτική ρύθμιση υπερ παραμέτρων, ενώ η διαδικασία εκπαίδευσης είναι πιο απαιτητική υπολογιστικά και τα αποτελέσματά τους δύσκολα ερμηνεύσιμα.

Γενικά, όλα τα μοντέλα επηρεάζονται από την ποιότητα των δεδομένων, πιθανές μεροληψίες στις έρευνες και την υπόθεση ότι τα χαρακτηριστικά του training set είναι αντιπροσωπευτικά των δεδομένων δοκιμής. Επίσης όλα απαιτούν κατάλληλο χειρισμό των NaN τιμών, το οποίο σε ένα test set παρεμβαίνει στην αξιοπιστία των prediction.


Στις δοκιμές για το test csv του διαγωνισμού χρησιμοποιήθηκε το Gradient Boosting, καθώς η ακρίβεια των προβλέψεων είναι το σημαντικότερο στα ζητούμενα. Το Gradient Boosting παρουσίασε τη χαμηλότερη τιμή MSE και το υψηλότερο R² στο validation set. Η ικανότητά του να μοντελοποιεί μη γραμμικές σχέσεις και αλληλεπιδράσεις μεταξύ των χαρακτηριστικών το καθιστά ιδιαίτερα κατάλληλο για δεδομένα κοινωνικοοικονομικών ερευνών.


Επίσης, για τον υπολογισμό του poverty distribution παίρνονται υπόψη οι καταγραφές στα pct_hh_below_#. Από το # προκύπτουν και τα poverty thresholds.
